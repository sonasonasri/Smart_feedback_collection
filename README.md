# 📊 Smart Feedback Collection Portal

## 🔍 Overview
The Smart Feedback Collection Portal is a web-based application designed to efficiently collect, manage, and analyze user feedback. It provides a simple interface for users to submit feedback and an administrative dashboard to monitor, filter, and evaluate responses.

The system helps organizations make better decisions by organizing feedback data and presenting it in a structured manner.

---

## 🚀 Features
- 📝 Easy-to-use feedback submission form  
- 📊 Admin dashboard to view and manage feedback  
- 🔎 Filter and analyze responses  
- ⚡ Real-time data processing  
- 🔐 Secure data handling  
- 📁 Organized storage of feedback records  

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Database: MySQL  

---

## 🧠 System Workflow
1. User submits feedback through the web interface  
2. Data is sent to the backend server  
3. Backend processes and stores feedback in the database  
4. Admin can view, filter, and analyze feedback  
5. Insights help in improving services and decision-making

## ⚙️ Installation & Setup

1. Clone the repository  
git clone https://github.com/yourusername/smart-feedback-portal  

2. Navigate to project directory  
cd smart-feedback-portal  

3. Install dependencies  
pip install -r requirements.txt  

4. Run the application  
python app.py  

5. Open in browser  
http://127.0.0.1:5000/
